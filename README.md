Цель данной работы заключалась в оптимизации вычислений над матричными линейными формами, путем использования множества потоков.
Файлы с содержимыми матриц должны быть в в том же каталоге что и CmakeLists.txt, и должны быть названны Ai.txt(A1.txt).
Матричная линейная форма задается в функции main и может содержать следующие конструкции Ai * - +(обязательно бинарный), ^(возведение в степень) , "()".
Нельзя записывать -- или -+ так же нельзя складывать числа с матрицами и тому подобные операции.
Для запуска makeSVG.sh (построение синтаксического дерева) вам потребудется graphiz.
Скрипт для генерации матриц называется create_files.sh. Результирующая матрица будет записана в файл Result.txt, матрицы записываются по строкам.
Проект использует Qt, все зависимости отражены в CmakeLists.txt .
Пример выполнения программы можно помотреть от отчете report_of_course_work.pdf.
